# Подписки по устройствам

В Telegram-боте: **Профили → Устройства → Добавить устройство**. Каждое
устройство получает собственную ссылку Happ с пользовательскими входами всех
нод. Если появится новый пользовательский вход или нода, control добавит его
в подписку при синхронизации (или при следующем открытии ссылки).

Для каждого устройства создаются отдельные учётные данные на каждом inbound.
Удаление устройства отзывает его ключи на всех нодах и закрывает ссылку
подписки; остальные устройства не затрагиваются. Входы `default:*` сюда не
включаются — в отличие от них, на этих входах применяются политики
маршрутизации.

Happ должен передавать заголовок `X-HWID` при запросе ссылки. Первый успешный
GET привязывает устройство к этому ID; без заголовка или с другим ID подписка
не отдаётся. В настройках Happ передача HWID должна быть включена. Привязка
ограничивает выдачу подписки, но уже загруженные конфиги и сам заголовок
`X-HWID` можно скопировать: это не аппаратная защита от передачи доступа.

Через gRPC доступны `control.ConfigService/CreateMyDevice` (поле `name`),
`ListMyDevices` и `DeleteMyDevice` (поле `id`). `CreateMyDevice` возвращает
ссылку `url`. Миграция `0016` добавляет устройства, не изменяя ранее
созданные одиночные профили и общие подписки. Миграция `0017` добавляет
привязку HWID (ранее созданные ссылки привяжутся при первом запросе).
